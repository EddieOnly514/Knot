# Knot

**Split rides. Stay safe. Save money.**

Ride-sharing matchmaking: find travelers to the same destination, match (NOW or LATER), coordinate via in-app chat, and split costs. Phone verification, ratings, Safety Center, and suggested meetup points.

## Tech Stack

- **Mobile** — React Native, Expo, TypeScript, React Navigation, Supabase
- **Web** — Next.js 16 (App Router), React 19, TypeScript, Tailwind, shadcn/ui, Supabase

## Getting Started

**Mobile:** `cd mobile && npm install && npx expo start`  
**Web:** `cd web && npm install && npm run dev`

Schema/migrations: `web/supabase/`
